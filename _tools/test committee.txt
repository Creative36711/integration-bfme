+## Определение исхода матча — `match_result_detector/`
+
+После окончания боя игра показывает экран статистики: на графике-таймлайне
+у победителей — золотые монеты, у проигравших — красные вспышки. Модуль:
+
+1. в фоне ждёт экран статистики (два маркера, подтверждение 2 кадра подряд);
+2. находит иконки победы/поражения (template matching + NMS);
+3. определяет цвет линии **слева от иконки**, сравнивая пиксели напрямую
+   с цветами игроков (они известны заранее — детерминированное
+   распределение цветов в комнате); у каждого цвета два эталона
+   (base/highlight), т.к. нитка выделенного игрока ярче;
+4. формирует результат: `match_status` (COMPLETED / SURRENDER / UNKNOWN),
+   `winners`, `losers`, `local_player_team_won` и сохраняет в
+   `config/match_result.json`; в 1v1 нераспознанная нитка доназначается
+   оставшемуся игроку.
+
+Захват кадра — **soft-fail**: `bridge/navigate.py` больше не кидает
+`OSError: GetClientRect failed`, при недоступном окне возвращает None
+(окно ищется заново каждый кадр, fallback — GetWindowRect), а детектор
+переключается на `PrintWindow`.
+
+**Детерминированные цвета (важно):** раньше при конфликте двух одинаковых
+фракций слоту оставлялся «Случайный» цвет — цвет линии на статистике был
+неизвестен. Теперь `room.determine_slot_colors()` назначает первый
+свободный цвет явно (тот же порядок использует `configure_room()` и сборка
+данных для детектора).
+
+Офлайн-проверка без игры:
+
+```bat
+python tools\test_detector.py --self-test

+python tools\test_match_result.py
+```
+
+`--players` принимает имена цветов (`blue`, `red`, ... — дают
+откалиброванный цвет нитки и оттенковый фильтр) или RRGGBB лобби-цвета
+(например `0049d0` — маппятся на ближайший лобби-цвет автоматически).

+def _frame_for_search(frame):
+    """Привести кадр к (H, W, 3) uint8 RGB."""

+# Определение исхода матча BFME2:RotWK
+
+Модуль автоматически определяет исход завершённого матча по **экрану
+статистики** (Score Screen): на графике-таймлайне находит иконки «Победа»
+(золотая монета) и «Поражение» (красная вспышка), определяет **цвет линии**
+под каждой иконкой и сопоставляет его с цветами игроков, которые были
+назначены в комнате **заранее** (детерминированное распределение цветов в
+`bridge/room.py`).
+
+```
+опрос и настройка комнаты (цвета известны ДО боя)
+  -> бой (ввод пользователя не блокирован)
+  -> экран статистики: фоновый мониторинг (каждые 1.5 c)
+     -> оба маркера экрана найдены (2 кадра подряд)
+     -> анализ: иконки + цвет линии слева от иконки
+     -> результат: {match_status, winners, losers, local_player_team_won}
+     -> config/match_result.json
+```
+
+## Зависимости
+
+* `numpy` — обязательна (как и для всего проекта);
+* `opencv-python` — **рекомендуется** (`pip install -r requirements.txt`):
+  шаблонный матчинг в ~20 раз быстрее. Без OpenCV работает встроенный
+  numpy-fallback (нормализованная кросс-корреляция через FFT, float32,
+  серые шаблоны считаются по 1 каналу) — результаты совпадают с cv2 до
+  ~1e-6. **Поиск всегда ограничен ROIs** (график, легенда и «Рейтинг»
+  исключены), поэтому даже fallback укладывается в ~1 с.
+
+## Структура модуля

+```json

+    "debug_files": [...]

+```
+
+`match_status`:
+
+| Статус | Когда |
+|---|---|
+| `COMPLETED` | Найдены иконки победы (и, возможно, поражения) |
+| `SURRENDER` | Только иконки поражения — сдача/выход; победители = выжившие |
+| `UNKNOWN` | Иконки не найдены или ни одна линия не сопоставлена (нужна калибровка) |
+| `TIMEOUT` | Анализ не уложился в `analysis_timeout` |
+
+## Как это работает (кратко)
+
+1. **Детекция экрана статистики.** Два независимых маркера: иконка
+   «Крепость» в легенде внизу (`fortress_roi`) и декоративный элемент
+   «Счёта» — **поиск по всему экрану** (`score_marker_roi = None`; сужение
+   зоны поиска ломало подтверждение экрана в реальном прогоне). Оба
+   должны быть найдены подряд `confirm_streak` кадров — это исключает
+   ложные срабатывания на боевом HUD. Чёрный кадр (BitBlt не видит
+   fullscreen-D3D) не считается кадром: монитор ждёт дальше и пишет
+   диагностику, а не «тихо» обрабатывает пустоту.
+2. **Поиск иконок.** `cv2.matchTemplate(TM_CCOEFF_NORMED)` в области графика
+   (`chart_roi`); при пустом результате — `icon_fallback_roi` (расширенная
+   область графика). **Легенда внизу экрана (y ≈ 840..905) и панель
+   «Рейтинг» (x ≥ 1460) полностью исключены из поиска**: там лежат ТОЧНЫЕ
+   копии шаблонов «Победа»/«Поражение», которые давали ложные иконки
+   (в реальном логе «Поражение» находилось на y=863 — это иконка легенды,
+   а не результат матча). Совпадения дедуплицируются NMS.
+3. **Цвет линии.** Иконка перекрывает линию, поэтому цвет читается **слева**
+   от неё (справа — fallback). Вместо «угадать самый частый цвет» пиксели
+   зоны сравниваются напрямую с **цветами известных игроков**: для каждого
+   считается число «своих» пикселей и максимальный непрерывный
+   горизонтальный забег; побеждает лучший забег >= `color_min_run`.
+   У каждого игрока **два эталона** цвета (base / highlight): нитка
+   выделенного в «Рейтинге» игрока ярче и насыщеннее, остальные
+   приглушены — пиксель считается «своим», если он близок хотя бы к
+   одному эталону (`network_prefs.COLOR_LINE_VARIANTS`).
+4. **Исход.** Иконка победа -> игрок в `winners`, поражение -> `losers`.
+   Только поражения -> `SURRENDER` (выжившие = победители). Ничего не
+   распознано -> `UNKNOWN`. `local_player_team_won` — есть ли хотя бы один
+   победитель из команды локального игрока.
+   **Fallback 1v1:** если в матче ровно 2 игрока и одна иконка осталась без
+   цвета (белая нитка не сматчилась), а второй игрок ещё не назначен —
+   иконка назначается ему (в `raw_data.fallback_assign_1v1`).
+   **Защита от конфликта:** если один игрок оказался и в `winners`, и в
+   `losers` (признак ложной иконки), он снимается с обеих сторон и
+   попадает в `raw_data.conflicts` — отчёт не выдаёт абсурдных результатов.
+
+## Калибровка на реальном скриншоте
+
+Зоны/пороги в `config.py` уже откалиброваны по реальному скриншоту
+1920x1080 с 7 игроками (`chart_roi` = 190..1310 x 240..815; иконки

+

+  тёмный фон не принимался за нитку, а свечение иконки отсекалось зоной

+Ключевые особенности реальных кадров (замеры на 7-игровом экране «Счёт»):
+
+1. Линии подходят к иконкам ПОД НАКЛОНОМ (зелёная в 40-90 px от иконки
+   на 12-26 px ниже её центра), поэтому «забег по строке» не работает —
+   нужен забег по СТОЛБЦАМ (per-column).
+2. Цвета линий сильно приглушены тёмным фоном и НЕ совпадают с
+   лобби-цветами игрока (см. bridge.network_prefs.COLORS_RGB).
+3. Около иконок много «чужих» элементов: свечение иконки, горизонтальные
+   сетки/рамки, глифы счёта, проходящие мимо линии других игроков
+   (белая проходит сквозь факелы красного/оранжевого, линии пучками
+   идут на расстоянии 3-15 px).
+4. Поэтому: пиксели должны быть ТОНКИМИ по вертикали (линия 1-3 px;
+   свечение/заливки — 15+ px), линия должна быть НАКЛОННОЙ (плоские
+   полосы = сетки/рамки -> отбрасываются), а точка пересечения
+   экстраполированной траектории с x=иконки должна быть близка к cy.
+5. Проходящая линия (например белая мимо факелов) находится и СЛЕВА,
+   и СПРАВА от иконки; «своя» линия заканчивается на иконке — справа её
+   нет. Это используется как развязка при почти равных траекториях.
+6. Дополнительно применяются «оттенковые» фильтры (r-g / g-b), когда у
+   игрока известно имя цвета (ключ "color" у dict игрока): они отделяют
+   близкие по RGB пары (жёлтая/оранжевая ≈ 27, белая/фиолетовая ≈ 23).
+"""

+# Порог «фоновости»: пиксели темнее этого значения (по среднему каналу)
+# не рассматриваются как цветная линия.
+BG_LUMA = 30.0
+
+# Максимум «толщины» линии в одном столбце (свечение/заливка — толще).
+MAX_THIN = 6
+
+# Ниже этой доли высоты кадра не анализируем: нижняя рамка графика
+# (y≈800 из 1080 на 1080p) — плоская серая полоса, ломающая матчинг.
+FRAME_EXCLUDE_FRAC = 0.737

+# ---------------------------------------------------------------------------
+# КАЛИБРОВАННЫЕ цвета ниток на реальном экране «Счёт» (7 игроков,
+# _tools/screenshots/stats_8.jpg, 1920x1080) — замеры точечными щупами
+# прямо у иконок исхода. Это НЕ лобби-цвета (COLORS_RGB) и НЕ «база*0.55»:
+#  * синяя нитка у пламени   ~ (48,58,89)  (база (78,90,132) далеко);
+#  * жёлтая/оливковая        ~ (52,54,27)..(85,88,60);
+#  * фиолетовая              ~ (50,46,60)..(69,66,77) — СИНЕ-фиолетовая,
+#    а не пыльно-розовая (140,122,128) из палитры;
+#  * оранжевая               ~ (63,52,38)..(80,69,58) (r-g всего 6-11).
+# Эталоны сведены к именам цвета (ключ "color" у dict игрока).

+    "yellow":     [(52, 54, 27), (85, 88, 60), (59, 64, 36), (48, 51, 25)],
+    "white":      [(127, 127, 127), (85, 85, 85), (74, 74, 74)],
+    "red":        [(60, 34, 33), (59, 35, 33), (54, 31, 28)],
+    "orange":     [(75, 69, 55), (63, 52, 38), (80, 69, 58), (87, 69, 52)],
+    "purple":     [(50, 46, 60), (69, 66, 77), (42, 36, 49)],
+    "light_blue": [(70, 85, 120), (90, 110, 160)],
+    "pink":       [(160, 120, 140)],

+def _color_distances(region, color_rgb):
+    """Евклидово расстояние в RGB от каждого пикселя зоны до цвета игрока.
+
+    Args:
+        region: (H, W, 3) uint8 массив зоны.
+        color_rgb: (r, g, b) целевой цвет.
+
+    Returns:
+        (H, W) float массив расстояний.
+    """
+    diff = region.astype(np.int32) - np.asarray(color_rgb, dtype=np.int32)
+    return np.sqrt((diff * diff).sum(axis=2))
+
+
+def _player_references(p):
+    """Базовый RGB-эталон игрока.
+
+    Используется ТОЛЬКО базовый цвет (refs[0]): «яркий» вариант из
+    COLOR_LINE_VARIANTS на реальных кадрах не встречается (даже у
+    выделенного в «Рейтинге» игрока нитка приглушена), а яркий эталон
+    путает близкие цвета (белый/фиолетовый).
+
+    Args:
+        p: dict игрока (faction_color_rgb / faction_color_variants).
+
+    Returns:
+        [(r, g, b)]; пустой, если цвет неизвестен.
+    """
+    refs = p.get("faction_color_variants")
+    if not refs:
+        base = p.get("faction_color_rgb")
+        refs = [base] if base is not None else []
+    refs = [r for r in refs if r is not None]
+    if not refs:
+        return []
+    return [tuple(int(v) for v in refs[0])]
+
+
+def _chart_refs(p) -> List[tuple]:
+    """Эталоны цвета НИТКИ игрока (реальный график «Счёт»).
+
+    Приоритет: калиброванные цвета CHART_COLOR_REFS по имени цвета; если
+    имя цвета неизвестно — база из лобби-палитры и её приглушённый вариант
+    (base * 0.55), как раньше.
+
+    Args:
+        p: dict игрока (color / faction_color_rgb).
+
+    Returns:
+        Список RGB-кортежей (не пустой, если цвет известен).
+    """
+    name = p.get("color")
+    refs = CHART_COLOR_REFS.get(name)
+    if refs:
+        return [tuple(int(v) for v in r) for r in refs]
+    base = _player_references(p)
+    if not base:
+        return []
+    base = base[0]
+    dim = tuple(int(v * 0.55) for v in base)
+    if dim == base:
+        return [base]
+    return [base, dim]
+
+
+def _line_refs(p) -> List[tuple]:
+    """Все эталоны нитки игрока: калиброванные цвета графика + база.
+
+    Синтетические фикстуры рисуют нитки ЧИСТЫМИ лобби-цветами
+    (0,255,0), а реальные — приглушёнными (45,68,58); объединение
+    эталонов покрывает оба случая, а hue-гварды разводят близкие пары.
+
+    Args:
+        p: dict игрока (color / faction_color_rgb / variants).
+
+    Returns:
+        Список RGB-кортежей (не пустой, если цвет известен), без дублей.
+    """
+    out = []
+    for refs in (_chart_refs(p), _player_references(p),
+                 p.get("faction_color_variants")):
+        if not refs:
+            continue
+        for ref in refs:
+            t = tuple(int(v) for v in ref)
+            if t not in out:
+                out.append(t)
+    return out
+

+def classify_line_pixel(rgb, players, cfg) -> Optional[int]:
+    """Классифицировать пиксель/усреднённый прогон нитки -> индекс игрока.
+
+    Пиксель относится к игроку, чей эталон (калиброванный цвет графика
+    ИЛИ базовая лобби-палитра/варианты) ближе всего (<= color_tolerance)
+    И чей оттенковый фильтр не противоречит. Пиксель, не похожий ни на
+    один эталон, не классифицируется (None).
+
+    Args:
+        rgb: (r, g, b) цвет пикселя.
+        players: список dict игроков.
+        cfg: DetectorConfig.
+
+    Returns:
+        Индекс игрока или None.
+    """
+    r, g, b = (int(v) for v in rgb)
+    best_idx = None
+    best_dist = float("inf")
+    for idx, p in enumerate(players):
+        refs = _line_refs(p)
+        if not refs:
+            continue
+        d = min(_color_distance(rgb, ref) for ref in refs)
+        if d < best_dist:
+            best_dist = d
+            best_idx = idx
+    if best_idx is None or best_dist > cfg.color_tolerance:
+        return None
+    name = players[best_idx].get("color")
+    if not name:
+        return best_idx
+    if not _hue_filter(name, np.asarray([[rgb]], dtype=np.uint8))[0, 0]:
+        return None
+    return best_idx
+
+
+def _color_distance(rgb, ref):
+    """Евклидово RGB-расстояние между пикселем и эталоном."""
+    return float(np.sqrt(
+        (rgb[0] - ref[0]) ** 2 + (rgb[1] - ref[1]) ** 2
+        + (rgb[2] - ref[2]) ** 2))
+
+
+def _hue_filter(name, region):
+    """Маска «оттенкового» фильтра для известного имени цвета.
+
+    Правила откалиброваны по РЕАЛЬНЫМ ниткам экрана «Счёт» (не по лобби):
+      blue    b-r >= 30, g >= r;         green  g-r >= 12, g-b в 0..25;
+      yellow  r-g <= 6, g-b >= 10, b <= r+6;
+      white   |r-g|<=16, |g-b|<=16;      red    r-g >= 16, g-b <= 10;
+      orange  r-g >= 5, g-b >= 4;        purple b-g >= 8, r >= g-4,
+                                          b-r <= 20 (сине-фиолетовая нитка!).
+    Возвращает None, если имя цвета неизвестно (тогда фильтр не
+    применяется — так работают синтетические фикстуры).
+    """
+    if not name:
+        return None
+    r = region[:, :, 0].astype(np.int32)
+    g = region[:, :, 1].astype(np.int32)
+    b = region[:, :, 2].astype(np.int32)
+    rg, gb, rb = r - g, g - b, r - b
+    if name == "blue":
+        return (b - r) >= 30
+    if name == "green":
+        # r заметно ниже g (реальная нитка (45,68,58): rg=-23; но чистая
+        # фикстура (0,255,0): rg=-255, gb=255 — ограничивать gb нельзя).
+        return rg <= -12
+    if name == "yellow":
+        # Реальная оливково-жёлтая нитка: r < g, b сильно ниже g
+        # (52,54,27): rg=-2, gb=27, rb=25.
+        return (rg <= 2) & (gb >= 20)
+    if name == "white":
+        # Реальная «белая» нитка слегка голубоватая ([85,85,85]..[133,146,154]),
+        # поэтому допуск больше, чем у строго серой легенды.
+        return (np.abs(rg) <= 16) & (np.abs(gb) <= 16)
+    if name == "red":
+        return (rg >= 16) & (gb <= 10)
+    if name == "orange":
+        # Реальная оранжевая нитка: r-g всего 6..11 (не 12+, как в палитре).
+        return (rg >= 5) & (gb >= 4)
+    if name == "purple":
+        # Реальная нитка Ангмара — СИНЕ-фиолетовая: b > g на 11-14,
+        # r чуть выше g (50,46,60): rg=4, gb=-14, rb=-10.
+        return (gb <= -8) & (rg >= -4) & (rb <= 20)
+    return None
+

+def _collect_columns(frame, x0, x1, cy, players, cfg):
+    """Собрать «тонкие» совпадения каждого игрока по столбцам.
+
+    Для каждого столбца зоны ищутся пиксели с расстоянием до базового
+    эталона <= color_tolerance, ярче BG_LUMA, прошедшие оттенковый фильтр
+    (если имя цвета известно). Столбец считается «своим», если таких
+    пикселей от 1 до MAX_THIN; в точке берётся средний y (центр линии).
+
+    Args:
+        frame: (H, W, 3) uint8 RGB.
+        x0, x1: зона по X.
+        cy: центр иконки по Y (ограничитель зоны).
+        players: список dict игроков.
+        cfg: DetectorConfig.
+
+    Returns:
+        dict: index -> список (x, y) «своих» точек линии.
+    """
+    h, w = frame.shape[:2]
+    x0 = max(0, int(x0)); x1 = min(w, int(x1))
+    y0 = max(0, int(cy - cfg.line_scan["dy"]))
+    y1 = min(h, int(cy + cfg.line_scan["dy"]) + 1)
+    y1 = min(y1, int(h * FRAME_EXCLUDE_FRAC))
+    if x1 <= x0 or y1 <= y0:
+        return {}
+
+    region = frame[y0:y1, x0:x1]
+    luma = region.astype(np.float32).mean(axis=2)
+    out = {}
+    for idx, p in enumerate(players):
+        refs = _player_references(p)
+        if not refs:
+            continue
+        mask = _color_distances(region, refs[0]) <= cfg.color_tolerance
+        mask &= luma >= BG_LUMA
+        hue = _hue_filter(p.get("color"), region)
+        if hue is not None:
+            mask &= hue
+        per_col = mask.sum(axis=0)
+        pts = []
+        for j in range(region.shape[1]):
+            if 1 <= per_col[j] <= MAX_THIN:
+                ys = np.where(mask[:, j])[0]
+                pts.append((x0 + j, float(y0 + float(ys.mean()))))
+        if pts:
+            out[idx] = pts
+    return out
+

+def _split_clusters(pts, x_gap=8.0):
+    """Разбить точки на кластеры по непрерывности по X.
+
+    Точки, отсортированные по x; разрыв между соседними x больше x_gap
+    начинает новый кластер. Позволяет отделить саму линию от свечения
+    иконки/глифов, случайно попавших в окно.
+
+    Args:
+        pts: список (x, y).
+        x_gap: максимальный разрыв внутри кластера (px).
+
+    Returns:
+        Список списков (x, y).
+    """
+    if not pts:
+        return []
+    ordered = sorted(pts)
+    clusters = [[ordered[0]]]
+    for p in ordered[1:]:
+        if p[0] - clusters[-1][-1][0] <= x_gap:
+            clusters[-1].append(p)
+        else:
+            clusters.append([p])
+    return clusters
+
+
+def _fit_trajectory(pts, cx, cy, cfg, local_span, min_n=None):
+    """Подогнать траекторию линии и экстраполировать её к x иконки.
+
+    Точки разбиваются на кластеры; подбирается лучший кластер (наибольшее
+    число точек при медианном остатке <= 4 px), чтобы свечение иконки или
+    панель не смешивали линии.
+
+    Args:
+        pts: список (x, y).
+        cx, cy: центр иконки.
+        cfg: DetectorConfig.
+        local_span: сколько последних пикселей использовать для наклона
+            (у конца линии кривизна меняется, глобальная экстраполяция
+            «промахивается»).
+        min_n: минимальное число точек (по умолчанию из конфига).
+
+    Returns:
+        dict(n, slope, y_end, dy, rms) или None (мало точек / артефакт).
+    """
+    if min_n is None:
+        min_n = int(cfg.line_scan.get("min_pts", 20.0))
+    candidates = []
+    for cluster in _split_clusters(pts):
+        n = len(cluster)
+        if n < max(min_n, 8):
+            continue
+        X = np.array([p[0] for p in cluster], dtype=float)
+        Y = np.array([p[1] for p in cluster], dtype=float)
+        m = X >= cx - local_span
+        if m.sum() >= 10:
+            Xf, Yf = X[m], Y[m]
+        else:
+            Xf, Yf = X, Y
+        slope, intercept = np.polyfit(Xf, Yf, 1)
+        resid = np.abs(Yf - (intercept + slope * Xf))
+        if float(np.median(resid)) > 4.0:
+            continue
+        slope_min = float(cfg.line_scan.get("slope_min", 0.008))
+        if abs(slope) < slope_min:
+            continue
+        y_end = intercept + slope * cx
+        candidates.append({
+            "n": n,
+            "slope": float(slope),
+            "y_end": float(y_end),
+            "dy": float(abs(y_end - cy)),
+            "rms": float(np.sqrt((resid * resid).mean())),
+        })
+    if not candidates:
+        return None
+    candidates.sort(key=lambda c: (-c["n"], c["rms"]))
+    best = candidates[0]
+    # Лучший кластер по (n, rms) может «промахнуться» по dy; но если есть
+    # кластер с dy заметно лучше и достаточным n — предпочитаем его.
+    for c in candidates[1:]:
+        if c["dy"] < best["dy"] * 0.6 and c["n"] >= max(8, min_n // 2):
+            best = c
+            break
+    return best
+

+def _staircase_analyze(frame, cx, cy, icon_w, icon_h, players, cfg, scale):
+    """Фолбэк для СТУПЕНЧАТЫХ линий графика (плато + вертикальные скачки).
+
+    На реальных вкладках статистики («Войска»/«Постройки»/«Ресурсы»/«Счёт»)
+    линии рисуются step-функцией: горизонтальные плато с вертикальными
+    переходами. Траекторный анализ выше предполагает НАКЛОННЫЕ линии
+    (slope_min) и рвёт кластеры на вертикальных скачках — такие линии он
+    не находит вовсе (best=None).
+
+    Этот фолбэк ищет:
+      1. «плато» — последние (до 30) точек непрерывного горизонтального
+         участка на одном уровне (rms <= 4), подходящие к иконке по y;
+      2. «коннектор» — короткий горизонтальный отрезок (>= 3 точек) прямо
+         на уровне иконки (dy <= 8), заканчивающийся рядом с ней;
+      3. вертикальный трейс — длинная (>= 25 px) вертикаль рядом с иконкой
+         (линия подходит сверху/снизу, как на «Ресурсы»/«Счёт»).
+
+    Цвета линий на этих кадрах сильно тёмнее палитры (синяя нитка ~
+    [37,45,82] при базе [78,90,132]), поэтому к базовому эталону добавляется
+    «приглушённый» вариант (base * 0.55).
+
+    Args:
+        frame: (H, W, 3) uint8 RGB.
+        cx, cy: центр иконки.
+        icon_w, icon_h: размеры иконки (для масштаба).
+        players: список dict игроков.
+        cfg: DetectorConfig.
+        scale: коэффициент масштаба кадра.
+
+    Returns:
+        dict {"player", "side", "best", "total_stats"} или None.
+    """
+    s = float(scale)
+    h, w = frame.shape[:2]
+    gap = float(cfg.line_scan.get("gap", 45.0)) * s
+    # Для ступенчатых линий зона чуть шире: хвост часто ниже/выше иконки.
+    scan_x = 300.0 * s
+    dy_band = 60.0 * s
+    tol = float(cfg.color_tolerance) * max(1.0, s)
+    hue = None  # фильтр применяется к каждому игроку отдельно
+
+    x_left = max(0.0, float(cfg.chart_roi[0]) * w)
+    x_right = min(float(w), float(cfg.chart_roi[2]) * w)
+    y_lim = int(h * FRAME_EXCLUDE_FRAC)
+
+    candidates = []  # (score_key, player_idx, info, side)
+    for idx, p in enumerate(players):
+        base = _player_references(p)
+        if not base:
+            continue
+        base = np.asarray(base[0], dtype=np.int32)
+        refs = [base, (base * 0.55).astype(np.int32)]  # база + приглушённый
+        hname = p.get("color")
+        def _mask(reg_x0, reg_x1, reg_y0, reg_y1):
+            x0 = max(0, int(reg_x0)); x1 = min(w, int(reg_x1))
+            y0 = max(0, int(reg_y0)); y1 = min(y_lim, int(reg_y1))
+            if x1 <= x0 or y1 <= y0:
+                return None, x0, x1, y0, y1
+            region = frame[y0:y1, x0:x1].astype(np.int32)
+            dist = np.min(
+                [np.sqrt(((region - r) ** 2).sum(axis=2)) for r in refs],
+                axis=0)
+            luma = region.astype(np.float32).mean(axis=2)
+            m = (dist <= tol) & (luma >= BG_LUMA)
+            hf = _hue_filter(hname, region)
+            if hf is not None:
+                m &= hf
+            return m, x0, x1, y0, y1
+
+        def _points(m, x0, y0):
+            """Тонкие точки по столбцам: (x, средний y)."""
+            per = m.sum(axis=0)
+            pts = []
+            for j in range(m.shape[1]):
+                if 1 <= per[j] <= MAX_THIN:
+                    ys = np.where(m[:, j])[0]
+                    pts.append((x0 + j, y0 + float(ys.mean())))
+            return pts
+
+        # --- 1) горизонтальная зона слева от иконки ---------------------
+        mh, x0, x1, y0, y1 = _mask(cx - gap - scan_x, cx - gap,
+                                   cy - dy_band, cy + dy_band)
+        best_h = None
+        if mh is not None:
+            pts = _points(mh, x0, y0)
+            clusters = _split_clusters(pts, x_gap=12.0 * s)
+            for cl in clusters:
+                if len(cl) < 2:
+                    continue
+                # «плато»: хвост кластера на одном уровне
+                tail = cl[-min(30, len(cl)):]
+                ys = np.array([p[1] for p in tail])
+                y_med = float(np.median(ys))
+                rms = float(np.median(np.abs(ys - y_med)))
+                plateau = (len(tail) >= 8 and rms <= 4.0
+                           and abs(y_med - cy) <= 22.0 * s)
+                # «коннектор»: короткий плоский отрезок на уровне иконки
+                y_last = cl[-1][1]
+                run = [cl[-1]]
+                for p in reversed(cl[:-1]):
+                    if (p[0] - run[-1][0] <= 4.0 * s
+                            and abs(p[1] - y_last) <= 8.0):
+                        run.append(p)
+                    else:
+                        break
+                run.reverse()
+                if len(run) < 3:
+                    tail3 = cl[-3:]
+                    ys3 = [q[1] for q in tail3]
+                    if max(ys3) - min(ys3) <= 8.0:
+                        run = tail3
+                connector = (len(run) >= 3
+                             and abs(float(np.median([q[1] for q in run]))
+                                     - cy) <= 8.0
+                             and run[-1][0] >= cx - 70.0 * s)
+                if plateau or connector:
+                    info = {
+                        "n": len(tail), "pts": len(cl),
+                        "y": y_med if plateau else float(np.median(
+                            [q[1] for q in run])),
+                        "x_last": cl[-1][0],
+                        "rms": rms,
+                        "kind": "plateau" if plateau else "connector",
+                    }
+                    key = (1 if plateau else 0, -abs(info["y"] - cy),
+                          -info["x_last"])
+                    if best_h is None or key > best_h[0]:
+                        best_h = (key, idx, info)
+
+        # --- 2) вертикальный трейс рядом с иконкой ----------------------
+        mv, vx0, vx1, vy0, vy1 = _mask(cx - 45.0 * s, cx + 15.0 * s,
+                                       cy - 300.0 * s, cy + 300.0 * s)
+        vlen = 0
+        if mv is not None:
+            per = mv.sum(axis=1)
+            rows = set((np.where((per >= 1) & (per <= 14))[0] + vy0).tolist())
+            def _trace(start_rows, direction):
+                best = 0
+                for sy in start_rows:
+                    last = sy; cnt = 0
+                    for y in range(sy, sy + direction * 300, direction):
+                        if y in rows:
+                            last = y; cnt += 1
+                        elif abs(y - last) <= 8:
+                            continue
+                        else:
+                            break
+                        if y < 0 or y >= y_lim:
+                            break
+                    best = max(best, cnt)
+                return best
+            down = _trace([y for y in rows if cy + 4 <= y <= cy + 60], 1)
+            up = _trace([y for y in rows if cy - 60 <= y <= cy - 4], -1)
+            vlen = max(down, up)
+        if vlen >= 25:
+            vinfo = {"n": vlen, "pts": vlen, "y": float(cy),
+                     "x_last": float(cx), "rms": 0.0, "kind": "vertical"}
+            vkey = (0, 0.0, -1e9)  # вертикаль — слабее плато/коннектора
+            if best_h is None or vkey > best_h[0]:
+                best_h = (vkey, idx, vinfo)
+
+        if best_h is not None:
+            candidates.append((best_h[0], best_h[1], best_h[2]))
+
+    if not candidates:
+        return None
+    candidates.sort(key=lambda c: c[0], reverse=True)
+    _, idx, info = candidates[0]
+    stats = [{
+        "index": idx,
+        "color_rgb": tuple(int(v) for v in
+                           _player_references(players[idx])[0]),
+        "max_run": info["n"],
+        "pixels": info["pts"],
+        "min_dist": float(info["rms"]),
+        "mean_dist": float(info["rms"]),
+        "y_end": float(info["y"]),
+        "slope": 0.0,
+        "dy_end": float(abs(info["y"] - cy)),
+    }]
+    return {"player": idx, "side": "left", "total_stats": stats,
+            "best": {"index": idx, **stats[0], "side": "left"}}
+
+
+def _scan_side(frame, cx, cy, players, cfg, side, local_span,
+               x_bounds=None):
+    """Собрать траектории всех игроков на одной стороне иконки.
+
+    Args:
+        frame: (H, W, 3) uint8 RGB.
+        cx, cy: центр иконки.
+        players: список игроков (цвета).
+        cfg: DetectorConfig.
+        side: "left" или "right".
+        local_span: длина локального участка для наклона (px).
+        x_bounds: (x_min, x_max) — допустимые границы по X (например,
+            края графика), чтобы справа не захватить панель «Рейтинг».
+
+    Returns:
+        dict: index -> результат _fit_trajectory (без фильтра по dy —
+        пороги применяет вызывающий код).
+    """
+    gap = float(cfg.line_scan.get("gap", 45.0))
+    length = float(cfg.line_scan.get("trace_len", 300.0))
+    if side == "left":
+        x1 = cx - gap
+        x0 = x1 - length
+    else:
+        x0 = cx + gap
+        x1 = x0 + length
+    if x_bounds is not None:
+        x0 = max(x0, x_bounds[0])
+        x1 = min(x1, x_bounds[1])
+    cols = _collect_columns(frame, x0, x1, cy, players, cfg)
+    out = {}
+    for idx, pts in cols.items():
+        fit = _fit_trajectory(pts, cx, cy, cfg, local_span)
+        if fit is not None:
+            out[idx] = fit
+    return out
+

+def _thin_column_points(frame, x0, x1, y0, y1, players, cfg):
+    """Тонкие прогоны нитей по столбцам -> [(x, y_center, player_idx)].
+
+    Каждый вертикальный прогон толщиной 1..MAX_THIN пикселей (нитка;
+    свечение/заливка толще) с luma >= BG_LUMA классифицируется по
+    калиброванному эталону (classify_line_pixel). Точка — центр прогона.
+
+    Args:
+        frame: (H, W, 3) uint8 RGB.
+        x0, x1, y0, y1: зона в пикселях.
+        players: список dict игроков.
+        cfg: DetectorConfig.
+
+    Returns:
+        Список (x, y_center, player_index).
+    """
+    h, w = frame.shape[:2]
+    x0 = max(0, int(x0)); x1 = min(w, int(x1))
+    y0 = max(0, int(y0)); y1 = min(h, int(y1))
+    if x1 <= x0 or y1 <= y0:
+        return []
+    out = []
+    for x in range(x0, x1):
+        col = frame[y0:y1, x]
+        luma = col.astype(np.float32).mean(axis=1)
+        ys = np.where(luma >= BG_LUMA)[0]
+        if len(ys) == 0:
+            continue
+        runs = []
+        start = ys[0]; prev = ys[0]
+        for y in ys[1:]:
+            if y - prev <= 1:
+                prev = y
+            else:
+                runs.append((start, prev)); start = y; prev = y
+        runs.append((start, prev))
+        for a, b in runs:
+            if 1 <= b - a + 1 <= MAX_THIN:
+                rgb = tuple(int(v) for v in col[a:b + 1].mean(axis=0))
+                idx = classify_line_pixel(rgb, players, cfg)
+                if idx is not None:
+                    out.append((x, y0 + (a + b) / 2.0, idx))
+    return out
+
+
+def _max_vertical_run(rows, cy):
+    """Длина непрерывной вертикали (допуск 8 px) рядом с cy.
+
+    Args:
+        rows: набор y-строк с «тонкими» пикселями одного игрока.
+        cy: центр иконки.
+
+    Returns:
+        Максимум подряд идущих строк, пересекающих полосу cy ± 60.
+    """
+    if not rows:
+        return 0
+    rows = sorted(set(rows))
+    best = 0
+    seg = [rows[0]]
+    for y in rows[1:]:
+        if y - seg[-1] <= 8:
+            seg.append(y)
+        else:
+            if seg[0] <= cy + 60 and seg[-1] >= cy - 60:
+                best = max(best, len(seg))
+            seg = [y]
+    if seg and seg[0] <= cy + 60 and seg[-1] >= cy - 60:
+        best = max(best, len(seg))
+    return best
+

+def _step_line_analyze(frame, cx, cy, players, cfg, scale=1.0):
+    """Основной анализ СТУПЕНЧАТЫХ линий (реальные вкладки статистики).
+
+    Линии таймлайна — step-функции (плато + вертикальные скачки), поэтому
+    «траекторный» анализ (наклонные прямые) их теряет. Здесь:
+
+      1. Слева от иконки в полосе cy ± dy_band собираются тонкие прогоны
+         нитей и классифицируются по КАЛИБРОВАННЫМ цветам (CHART_COLOR_REFS).
+      2. Кандидат — кластер, который ДОХОДИТ до иконки (x_last) и НЕ
+         продолжается СПРАВА (проходящая линия отбрасывается: своя линия
+         заканчивается на иконке).
+      3. Лучший кандидат — самый близкий по y к cy (развязка: ближе к
+         иконке по x, больше точек).
+      4. Если слева кандидатов нет — вертикальный трейс рядом с иконкой
+         (линия подходит сверху/снизу, как на синтетической фикстуре).
+
+    Args:
+        frame: (H, W, 3) uint8 RGB.
+        cx, cy: центр иконки.
+        players: список dict игроков.
+        cfg: DetectorConfig.
+        scale: коэффициент масштаба кадра.
+
+    Returns:
+        dict {"player", "side", "total_stats", "best"} или None.
+    """
+    s = float(scale)
+    h, w = frame.shape[:2]
+    sc = cfg.step_line_scan
+    gap = float(sc.get("gap", 45.0)) * s
+    scan_x = float(sc.get("scan_x", 300.0)) * s
+    dy_band = float(sc.get("dy_band", 55.0)) * s
+    min_pts = int(sc.get("min_pts", 6.0))
+    x_last_min = float(sc.get("x_last_min", 90.0)) * s
+    pass_dx = float(sc.get("pass_dx", 110.0)) * s
+    pass_dy = float(sc.get("pass_dy", 45.0)) * s
+    cluster_gap = float(sc.get("cluster_gap", 12.0)) * s
+    y_lim = int(h * FRAME_EXCLUDE_FRAC)
+
+    lx0 = max(0.0, float(cfg.chart_roi[0]) * w)
+    # Окно слева ДОХОДИТ почти до иконки (cx - end_gap), а не до cx-gap:
+    # последний вертикальный ступенчатый подъём/спуск к иконке происходит
+    # в x [cx-gap, cx-25] и без него конец кластера завышается.
+    end_gap = float(sc.get("end_gap", 25.0)) * s
+    lx1 = max(0, int(cx - end_gap))
+    rx0 = max(0, int(cx + max(gap * 0.7, 25.0 * s)))
+    # ЗАКРЫТЬ правую зону границей графика: правее (x >= chart_roi[2])
+    # панель «Рейтинг» с цветными иконками фракций — она захламляла
+    # «проходящую» проверку сотнями ложных точек (синие 525 шт. у пламени
+    # 1225 — это иконка фракции в рейтинге, а не линия).
+    rx1 = min(w, int(cx + max(gap * 0.7, 25.0 * s) + scan_x),
+              int(float(cfg.chart_roi[2]) * w))
+    y0 = max(0, int(cy - dy_band))
+    y1 = min(y_lim, int(cy + dy_band) + 1)
+
+    left = _thin_column_points(frame, lx0, lx1, y0, y1, players, cfg)
+    # ПРАВАЯ зона собирается в ШИРОКОЙ полосе (cy ± pass_band, а не
+    # cy ± dy_band): проходящая нитка сразу за иконкой может уходить из
+    # узкой полосы (белая у пламени 804 за 40px уходит с 713 на 660), и
+    # тогда она не отсеивается и перехватывает иконку.
+    pass_band = float(sc.get("pass_band", 150.0)) * s
+    ry0 = max(0, int(cy - pass_band))
+    ry1 = min(y_lim, int(cy + pass_band) + 1)
+    right = _thin_column_points(frame, rx0, rx1, ry0, ry1, players, cfg)
+
+    by_l: Dict[int, List[tuple]] = {}
+    for x, y, idx in left:
+        by_l.setdefault(idx, []).append((x, y))
+    by_r: Dict[int, List[tuple]] = {}
+    for x, y, idx in right:
+        by_r.setdefault(idx, []).append((x, y))
+
+    # Кластеры слева для каждого игрока (одна линия = один игрок, но
+    # свечение пламени/монеты «стирает» 12-40px нитки и рвёт кластер;
+    # разрывы трактуем как СВЯЗАННЫЕ концы одной линии).
+    left_clusters: Dict[int, List[tuple]] = {}
+    for idx, pts in by_l.items():
+        clusters = []
+        for cl in _split_clusters(pts, x_gap=cluster_gap):
+            if len(cl) < min_pts:
+                continue
+            x_last = cl[-1][0]
+            if x_last < cx - x_last_min:
+                continue  # обрывок в стороне, до иконки не дотягивается
+            tail = cl[-min(5, len(cl)):]
+            y_end = float(np.median([p[1] for p in tail]))
+            clusters.append((cl, x_last, y_end))
+        if clusters:
+            left_clusters[idx] = clusters
+
+    # «Проходящая» линия проверяется ПО ИГРОКУ: если линия игрока
+    # достигает иконки слева И продолжается справа кластером >=3 точек,
+    # начинающимся не дальше pass_dx от конца левого кластера и близким
+    # по y (любая точка — линия после иконки может уходить ступенькой),
+    # то игрок НЕ владелец иконки (его нитка прошла мимо/сквозь).
+    passing_players = set()
+    for idx, clusters in left_clusters.items():
+        for cl, x_last, y_end in clusters:
+            for rcl in _split_clusters(by_r.get(idx, ()),
+                                       x_gap=cluster_gap):
+                if len(rcl) < 3:
+                    continue
+                if rcl[0][0] - x_last > pass_dx:
+                    continue
+                if any(abs(yr - y_end) <= pass_dy for _, yr in rcl):
+                    passing_players.add(idx)
+                    break
+            if idx in passing_players:
+                break
+
+    candidates = []
+    stats = []
+    for idx, clusters in left_clusters.items():
+        if idx in passing_players:
+            continue
+        for cl, x_last, y_end in clusters:
+            candidates.append((abs(y_end - cy), -x_last, -len(cl),
+                               idx, x_last, y_end, len(cl), "left"))
+            stats.append({
+                    "index": idx,
+                    "color_rgb": _chart_refs(players[idx])[0]
+                    if _chart_refs(players[idx]) else None,
+                    "max_run": len(cl),
+                    "pixels": len(cl),
+                    "min_dist": 0.0,
+                    "mean_dist": 0.0,
+                    "y_end": y_end,
+                    "slope": 0.0,
+                    "dy_end": abs(y_end - cy),
+                    "passing": False,
+                })
+
+    # Вертикальный трейс — только если слева кандидатов нет (линия
+    # подходит к иконке сверху/снизу).
+    if not candidates:
+        vx0 = max(0, int(cx - 45.0 * s))
+        vx1 = min(w, int(cx + 15.0 * s))
+        vy0 = max(0, int(cy - 300.0 * s))
+        vy1 = min(y_lim, int(cy + 300.0 * s))
+        vpts = _thin_column_points(frame, vx0, vx1, vy0, vy1, players, cfg)
+        by_v: Dict[int, List[tuple]] = {}
+        for x, y, idx in vpts:
+            by_v.setdefault(idx, []).append((x, y))
+        for idx, pts in by_v.items():
+            vlen = _max_vertical_run([p[1] for p in pts], cy)
+            if vlen >= 25:
+                candidates.append((0.0, 0.0, -vlen, idx, float(cx),
+                                   float(cy), vlen, "vertical"))
+                stats.append({
+                    "index": idx,
+                    "color_rgb": _chart_refs(players[idx])[0]
+                    if _chart_refs(players[idx]) else None,
+                    "max_run": vlen,
+                    "pixels": vlen,
+                    "min_dist": 0.0,
+                    "mean_dist": 0.0,
+                    "y_end": float(cy),
+                    "slope": 0.0,
+                    "dy_end": 0.0,
+                    "passing": False,
+                })
+
+    if not candidates:
+        return None
+    candidates.sort(key=lambda c: (c[0], c[1], c[2]))
+    _, _, _, idx, x_last, y_end, n, side0 = candidates[0]
+    best = {
+        "index": idx,
+        "side": side0,
+        "y_end": y_end,
+        "slope": 0.0,
+        "dy_end": abs(y_end - cy),
+        "max_run": n,
+        "pixels": n,
+        "min_dist": 0.0,
+        "mean_dist": 0.0,
+        "color_rgb": _chart_refs(players[idx])[0]
+        if _chart_refs(players[idx]) else None,
+    }
+    return {"player": idx, "side": "left", "total_stats": stats, "best": best}
+

+def analyze_line_at_icon(frame, cx, cy, icon_w, icon_h, players, cfg,
+                         scale=1.0):
+    """Определить владельца линии у иконки.
+
+    Основной алгоритм — _step_line_analyze (калиброванные цвета нитки +
+    отсечение проходящих линий); запасной «траекторный» путь:
+
+      1. Слева от иконки в полосе cy ± dy собираются тонкие совпадения
+         пикселей с базовыми эталонами игроков.
+      2. Для каждого игрока подгоняется прямая (по последним
+         local_span px) и экстраполируется к x иконки: кандидат должен
+         «приходить» в иконку (dy <= max_dy).
+      3. Проходящие линии (есть и справа) отклоняются: если у лучшего
+         кандидата и идущего следом почти одинаковый dy (<= tie_dy),
+         выбирается тот, чья линия НЕ продолжается справа (своя линия
+         заканчивается на иконке).
+      4. Если слева валидных кандидатов нет — ищем справа.
+
+    Args:
+        frame: (H, W, 3) uint8 RGB.
+        cx, cy: центр иконки.
+        icon_w, icon_h: размеры иконки в пикселях кадра.
+        players: список игроков (цвета).
+        cfg: DetectorConfig.
+        scale: коэффициент масштаба кадра.
+
+    Returns:
+        dict: {"player": индекс или None, "side": "left"/"right"/None,
+               "total_stats": [...], "best": {...}}.
+    """
+    s = float(scale)
+    h, w = frame.shape[:2]
+    # Основной путь: ступенчатые линии + калиброванные цвета + проходящие.
+    try:
+        step = _step_line_analyze(frame, cx, cy, players, cfg, scale)
+    except Exception:  # noqa: BLE001 - основной путь не должен ронять анализ
+        log_stair_exc()
+        step = None
+    if step is not None:
+        return step
+    gap = max(float(cfg.line_scan.get("gap", 45.0)) * s,
+              icon_w * float(cfg.line_scan.get("dx_offset", 0.70)))
+    length = float(cfg.line_scan.get("trace_len", 300.0)) * s
+    local_span = min(length, 170.0 * s)
+    max_dy = float(cfg.line_scan.get("max_dy", 12.0)) * s
+    pass_dy = float(cfg.line_scan.get("pass_dy", 25.0)) * s
+    tie_dy = float(cfg.line_scan.get("tie_dy", 5.0)) * s
+    # Справа не заходить в панель «Рейтинг» / легенду: границы графика.
+    x_left = max(0.0, float(cfg.chart_roi[0]) * w)
+    x_right = min(float(w), float(cfg.chart_roi[2]) * w)
+    bounds = (x_left, x_right)
+
+    left = _scan_side(frame, cx, cy, players, cfg, "left", local_span,
+                      bounds)

+                "max_run": fit["n"],
+                "pixels": fit["n"],
+                "min_dist": float(fit["rms"]),
+                "mean_dist": float(fit["rms"]),
+                "y_end": fit["y_end"],
+                "slope": fit["slope"],
+                "dy_end": fit["dy"],
+            })
+        return stats

+    def pick(candidates, pass_through, side_name):
+        if not candidates:
+            return None, None
+        ordered = sorted(candidates.items(),
+                         key=lambda kv: (kv[1]["dy"], -kv[1]["n"]))
+        top_idx, top = ordered[0]
+        best = dict(top)
+        best["index"] = top_idx
+        if len(ordered) > 1 and top_idx in pass_through:
+            second_idx, second = ordered[1]
+            if (second_idx not in pass_through
+                    and second["dy"] <= top["dy"] + tie_dy):
+                best = dict(second)
+                best["index"] = second_idx
+        best["side"] = side_name

+        if cfg.scan_right_fallback:

+                           if v["dy"] <= max_dy}
+            top_idx, best = pick(right_final, set(), "right")
+            side = "right" if best is not None else None
+
+    stats = build_stats(left) + build_stats(right)
+    if best is not None:
+        return {
+            "player": best["index"] if best else None,
+            "side": side,
+            "total_stats": stats,
+            "best": best,
+        }
+
+    # Фолбэк для СТУПЕНЧАТЫХ линий (см. _staircase_analyze): на реальных
+    # вкладках статистики линии — step-функции, и траекторный анализ выше
+    # их не находит. Вызывается только если основной путь не дал кандидата.
+    try:
+        stair = _staircase_analyze(frame, cx, cy, icon_w, icon_h,
+                                   players, cfg, scale)
+    except Exception:  # noqa: BLE001 - фолбэк не должен ронять анализ
+        log_stair_exc()
+        stair = None
+    if stair is not None:
+        return stair
+    return {
+        "player": None,
+        "side": None,
+        "total_stats": stats,
+        "best": None,
+    }

+            return 1.0
+        return min(width / ref_w, height / ref_h)

+        y1 = max(y0 + 1, min(height, int(fy1 * height)))
+        return (x0, y0, x1, y1)

+def _is_black_frame(frame):
+    """True, если кадр чёрный/пустой (нет реального рендера D3D).

+        frame: (H, W, 3) uint8 RGB.

+    Returns:

+    def _capture_frame(self):
+        """Сделать скриншот через указанный capture (с защитой от ошибок).
+
+        Ошибки НЕ роняют монитор: возвращаем None. Лог — warning без
+        traceback (не чаще раза в 30 сек), чтобы не забивать консоль,
+        пока окно временно недоступно. Плюс: чёрный кадр не считается
+        кадром — это признак того, что BitBlt/PrintWindow не видят
+        fullscreen-D3D, а не «экран без маркеров».

+            return None

+            if frame is None:
+                self._log_capture_fail("capture returned None")
+                return None
+            frame = np.asarray(frame)
+            if frame.ndim == 2:
+                frame = np.stack([frame] * 3, axis=-1)
+            if frame.ndim != 3 or frame.shape[2] < 3:
+                self._log_capture_fail("capture returned bad shape")
+                return None
+            frame = frame[:, :, :3].astype(np.uint8, copy=False)
+            if _is_black_frame(frame):
+                self._log_capture_fail(
+                    "capture returned black frame (fullscreen-D3D not "
+                    "visible via GDI/PrintWindow) — need DXGI capture")
+                return None
+            if self._screen_resolution is None:
+                self._screen_resolution = (frame.shape[1], frame.shape[0])
+            self._capture_fail_reason = None
+            # Диагностика (не чаще 1/30 с): что за кадр приходит.
+            now = time.monotonic()
+            if now - self._last_capture_ok_log >= 30.0:
+                self._last_capture_ok_log = now
+                log.info("capture ok: %dx%d mean=%.1f max=%d "
+                         "(black frame: mean<%.0f or bright<%.4f)",
+                         frame.shape[1], frame.shape[0],
+                         float(frame.mean()), int(frame.max()),
+                         BLACK_FRAME_MEAN, BLACK_FRAME_BRIGHT_RATIO)
+            return frame
+        except Exception:  # noqa: BLE001
+            self._log_capture_fail("capture raised exception")
+            return None

+        Args:

+             int(round(i.get("cy", 0.0) / tol)),
+             i.get("player_index"))
+            for i in icons))

+"""
+Поиск иконок и шаблонов на кадре: template matching + Non-Maximum Suppression.
+
+Основной бэкенд — OpenCV (cv2.matchTemplate, TM_CCOEFF_NORMED). Если OpenCV
+не установлен, используется встроенный fallback на NumPy (нормализованная
+кросс-корреляция через FFT), чтобы модуль работал и в минимальном окружении
+(проект требует только numpy).
+
+Результаты обоих бэкендов сведены к одинаковому формату:
+    (x, y, score)   — x, y = ЦЕНТР совпадения, score 0..1
+"""

+import os

+import numpy as np

+try:  # pragma: no cover - наличие OpenCV зависит от окружения
+    import cv2
+except Exception:  # noqa: BLE001 - любой сбой импорта = нет OpenCV

+def resize_image(image, new_w, new_h):
+    """Масштабировать изображение.
+
+    Args:
+        image: numpy (H, W[, C]) uint8.
+        new_w: новая ширина.
+        new_h: новая высота.
+
+    Returns:
+        Изображение (new_h, new_w[, C]).

+    if image.shape[1] == new_w and image.shape[0] == new_h:
+        return image

+        return cv2.resize(image, (new_w, new_h), interpolation=interp)

+    ys = np.round(np.linspace(0, image.shape[0] - 1, new_h)).astype(int)
+    xs = np.round(np.linspace(0, image.shape[1] - 1, new_w)).astype(int)

+# ---------------------------------------------------------------------------
+# Template matching

+def _corr_fft(image, kernel):
+    """Полная перекрёстная корреляция image с kernel через FFT (numpy fallback).
+
+    C[i, j] = sum_{a,b} image[i + a, j + b] * kernel[a, b]   (valid-область).
+
+    Args:
+        image: 2D float массив (H, W).
+        kernel: 2D float массив (Kh, Kw).
+
+    Returns:
+        2D массив (H, W) — корреляция для каждого положения левого верхнего угла.
+    """
+    h, w = image.shape
+    kh, kw = kernel.shape
+    fh, fw = h + kh - 1, w + kw - 1
+    image = np.asarray(image, dtype=np.float32)
+    kernel = np.asarray(kernel, dtype=np.float32)
+    # correlation == convolution с перевёрнутым ядром
+    i_f = np.fft.rfft2(image, s=(fh, fw))
+    k_f = np.fft.rfft2(kernel[::-1, ::-1], s=(fh, fw))
+    conv = np.fft.irfft2(i_f * k_f, s=(fh, fw))
+    # Сдвиг K-1: результат conv[i] соответствует корреляции с верхним левым
+    # углом шаблона в позиции i - (K - 1). Оставляем только те позиции,
+    # где шаблон целиком помещается в изображение.
+    return conv[kh - 1:kh - 1 + (h - kh + 1),
+                kw - 1:kw - 1 + (w - kw + 1)]

+def _is_gray_template(templ):
+    """True, если шаблон практически серый (каналы близки).
+
+    Для таких шаблонов (крепость, декоративная рамка «Счёта») numpy-fallback
+    считает корреляцию по ОДНОМУ каналу luma — в 3 раза быстрее и точнее
+    не становится хуже. Цветные шаблоны (золотая монета, красная вспышка)
+    остаются полноцветными.
+
+    Args:
+        templ: (Kh, Kw, 3) uint8.
+
+    Returns:
+        True/False.
+    """
+    if templ.ndim == 2:
+        return True
+    mean_c = templ.reshape(-1, 3).mean(axis=0)
+    return float(mean_c.max() - mean_c.min()) < 20.0
+

+def _luma(image):
+    """Среднее по каналам -> 2D uint8 (быстрый luma для серых шаблонов)."""
+    if image.ndim == 2:
+        return image
+    return image.astype(np.float32).mean(axis=2).astype(np.uint8)
+

+def _ncc_2d(image, templ, threshold):
+    """Нормализованная кросс-корреляция для ОДНОГО канала (float32).
+
+    Args:
+        image: 2D float32 массив.
+        templ: 2D float32 массив.
+
+    Returns:
+        Список (x, y, score) — левые верхние углы.
+    """
+    ih, iw = image.shape
+    th, tw = templ.shape
+    oh, ow = ih - th + 1, iw - tw + 1
+    n = float(th * tw)
+    ones = np.ones((th, tw), dtype=np.float32)
+
+    t_hat = templ - templ.mean()
+    num = _corr_fft(image, t_hat)
+    var_t = float((t_hat ** 2).sum())
+    s1 = _corr_fft(image, ones)
+    s2 = _corr_fft(image * image, ones)
+    var_i = np.maximum(s2 - (s1 * s1) / n, 0.0)
+
+    denom = np.sqrt(var_i * var_t)
+    with np.errstate(divide="ignore", invalid="ignore"):
+        scores = np.where(denom > 1e-9, num / denom, 0.0)
+    hits = np.argwhere(scores >= threshold)
+    return [(int(x), int(y), float(scores[y, x])) for y, x in hits]

+def match_template_numpy(image, templ, threshold):
+    """Numpy-fallback cv2.matchTemplate(TM_CCOEFF_NORMED).
+
+    Считается по 1 каналу для серых шаблонов (быстрее в ~3 раза) и по
+    3 каналам с суммированием для цветных. float32 вместо float64 —
+    точность ~1e-6 от cv2 сохраняется, скорость выше.
+
+    Args:
+        image: (H, W, 3) uint8 RGB (или 2D).
+        templ: (Kh, Kw, 3) uint8 RGB (или 2D).
+        threshold: порог 0..1.
+
+    Returns:
+        Список (x, y, score).
+    """
+    ih, iw = image.shape[:2]
+    th, tw = templ.shape[:2]
+    if ih < th or iw < tw:
+        return []
+
+    if _is_gray_template(templ):
+        return _ncc_2d(_luma(image).astype(np.float32),
+                       _luma(templ).astype(np.float32), threshold)
+
+    if image.ndim == 2:
+        image = np.stack([image] * 3, axis=-1)
+    if templ.ndim == 2:
+        templ = np.stack([templ] * 3, axis=-1)
+
+    t = templ.astype(np.float32)
+    n = float(th * tw)
+    ones = np.ones((th, tw), dtype=np.float32)
+    oh, ow = ih - th + 1, iw - tw + 1  # число валидных позиций шаблона
+
+    # Числитель: sum_c sum (I_c * t_hat_c). (Среднее окна не нужно:
+    # sum(t_hat) == 0, поэтому sum((I - mean_I) * t_hat) == sum(I * t_hat).)
+    num = np.zeros((oh, ow), dtype=np.float32)
+    var_t = 0.0
+    var_i = np.zeros((oh, ow), dtype=np.float32)
+    for c in range(3):
+        im_c = image[:, :, c].astype(np.float32)
+        t_c = t[:, :, c]
+        t_hat = t_c - t_c.mean()
+        num += _corr_fft(im_c, t_hat)
+        var_t += float((t_hat ** 2).sum())
+        # var_I_c = sum I_c^2 - (sum I_c)^2 / N  (в каждом окне)
+        s1 = _corr_fft(im_c, ones)
+        s2 = _corr_fft(im_c * im_c, ones)
+        var_i += np.maximum(s2 - (s1 * s1) / n, 0.0)
+
+    denom = np.sqrt(var_i * var_t)
+    with np.errstate(divide="ignore", invalid="ignore"):
+        scores = np.where(denom > 1e-9, num / denom, 0.0)
+
+    hits = np.argwhere(scores >= threshold)
+    return [(int(x), int(y), float(scores[y, x])) for y, x in hits]
+

+def match_template(image, templ, threshold):
+    """Найти совпадения шаблона на кадре.
+
+    Args:
+        image: (H, W, 3) uint8 RGB (или grayscale).
+        templ: (Kh, Kw, 3) uint8 RGB.
+        threshold: порог TM_CCOEFF_NORMED 0..1.
+
+    Returns:
+        Список (x, y, score), где x, y — левый верхний угол совпадения.
+    """
+    if _USE_CV2:
+        if image.ndim == 2 or templ.ndim == 2:
+            res = cv2.matchTemplate(image, templ, cv2.TM_CCOEFF_NORMED)
+        else:
+            res = cv2.matchTemplate(
+                image[:, :, ::-1], templ[:, :, ::-1], cv2.TM_CCOEFF_NORMED)
+        loc = np.where(res >= threshold)
+        return [(int(x), int(y), float(res[y, x])) for y, x in zip(*loc)]
+    return match_template_numpy(image, templ, threshold)
+

+def apply_nms(points, min_distance):
+    """Non-Maximum Suppression по точкам (x, y, score).
+
+    Args:
+        points: список (x, y, score) в любом порядке.
+        min_distance: минимальная дистанция между сохраняемыми точками.
+
+    Returns:
+        Отфильтрованный список (x, y, score) — сначала самые уверенные.
+    """
+    if not points:
+        return []
+    ordered = sorted(points, key=lambda p: -p[2])
+    kept = []
+    for p in ordered:
+        x, y = p[0], p[1]
+        if all((x - kx) ** 2 + (y - ky) ** 2 >= min_distance ** 2
+               for kx, ky, _ in kept):
+            kept.append(p)
+    return kept
+

+def find_template(frame, templ, roi, threshold, nms_distance):
+    """Найти шаблон в прямоугольной области кадра с NMS.
+
+    Args:
+        frame: (H, W, 3) uint8 RGB.
+        templ: (Kh, Kw, 3) uint8 RGB.
+        roi: (x0, y0, x1, y1) в пикселях (None = весь кадр).
+        threshold: порог совпадения 0..1.
+        nms_distance: мин. дистанция между совпадениями.
+
+    Returns:
+        Список (cx, cy, score) — ЦЕНТРЫ совпадений.
+    """
+    h, w = frame.shape[:2]
+    if roi is None:
+        x0, y0, x1, y1 = 0, 0, w, h
+    else:
+        x0, y0, x1, y1 = (int(v) for v in roi)
+    x0 = max(0, x0)
+    y0 = max(0, y0)
+    x1 = min(w, x1)
+    y1 = min(h, y1)
+    th, tw = templ.shape[:2]
+    if x1 - x0 < tw or y1 - y0 < th:
+        return []
+
+    region = frame[y0:y1, x0:x1]
+    tops = match_template(region, templ, threshold)
+    if not tops:
+        return []
+
+    # Верхний левый угол -> центр, затем NMS.
+    points = [(x + tw / 2.0, y + th / 2.0, s) for x, y, s in tops]
+    kept = apply_nms(points, nms_distance)
+    return [(round(kx + x0, 1), round(ky + y0, 1), ks)
+            for kx, ky, ks in kept]

+"""
+Сопоставление цветов линий с игроками и формирование итогового результата.
+
+Вход — список игроков, у каждого: name, faction_color_rgb, team,
+is_local_player (см. README модуля).
+
+Логика исхода:
+  * Есть и иконки победы, и иконки поражения  -> COMPLETED.
+  * Только поражения (обычно: все уже проиграли, последний сдался / вышел)
+    -> SURRENDER, победителями считаем всех, у кого поражение НЕ найдено.
+  * Только победы -> COMPLETED, проигравшими считаем всех без иконки победы.
+  * Ни одной распознанной иконки -> UNKNOWN (нужна калибровка).
+"""
+
+import logging
+import math
+from typing import Dict, List, Optional
+
+log = logging.getLogger("match_detector.matcher")
+
+
+def nearest_player(rgb, players, max_distance=80.0):
+    """Найти игрока с наиболее близким цветом по евклидову расстоянию в RGB.
+
+    Args:
+        rgb: (r, g, b) обнаруженный цвет линии.
+        players: список игроков.
+        max_distance: если ближайший цвет дальше этого порога — вернуть None.
+
+    Returns:
+        (player_index, distance) или (None, None).
+    """
+    best_idx = None
+    best_dist = float("inf")
+    for i, p in enumerate(players):
+        if p.get("faction_color_rgb") is None:
+            continue  # цвет неизвестен — игрок не участвует
+        pr, pg, pb = (int(v) for v in p["faction_color_rgb"])
+        d = math.sqrt((pr - rgb[0]) ** 2 + (pg - rgb[1]) ** 2
+                      + (pb - rgb[2]) ** 2)
+        if d < best_dist:
+            best_dist = d
+            best_idx = i
+    if best_idx is None or best_dist > max_distance:
+        return None, None
+    return best_idx, best_dist
+
+
+def _player_summary(players, index):
+    """Краткое описание игрока (для результатов и логов)."""
+    p = players[index]
+    rgb = p.get("faction_color_rgb")
+    return {
+        "name": p.get("name", f"player-{index}"),
+        "slot": p.get("slot"),
+        "team": p.get("team"),
+        "faction_color_rgb": list(rgb) if rgb is not None else None,
+        "is_local_player": bool(p.get("is_local_player", False)),
+    }

+def determine_team_victory(winners, losers, players):
+    """Победила ли команда локального игрока.
+
+    Args:
+        winners: список summary-словарей победителей.
+        losers: список summary-словарей проигравших.
+        players: исходный список игроков.
+
+    Returns:
+        True/False; None, если локальный игрок не найден.
+    """
+    local = next((i for i, p in enumerate(players)
+                  if p.get("is_local_player")), None)
+    if local is None:
+        return None
+    local_team = players[local].get("team")
+    for w in winners:
+        if w["team"] == local_team:
+            return True
+    return False

+                 assign_unmatched_1v1=True):

+
+    Args:
+        players: список игроков (порядок фиксирован).
+        icon_assignments: список dict по иконкам:

+            осталась без цвета (например, белая нитка Изенгарда не
+            сматчилась), а второй игрок ещё не назначен — назначить её
+            ему. Победа/поражение при этом не угадывается, только
+            «оставшийся» игрок.
+
+    Returns:
+        dict в формате п. 5.6 рекомендации.
+    """
+    raw = dict(raw or {})
+    icons = [dict(i) for i in icon_assignments]
+
+    if assign_unmatched_1v1 and len(players) == 2:
+        unmatched = [i for i in icons if i.get("player") is None]
+        assigned = {i["player"] for i in icons
+                    if isinstance(i.get("player"), int)}

+                     if idx not in assigned]

+            unmatched[0]["player"] = remaining[0]
+            raw["fallback_assign_1v1"] = True
+            log.info("1v1 fallback: icon %s @(%s,%s) -> player #%s",
+                     unmatched[0]["kind"], unmatched[0].get("cx"),
+                     unmatched[0].get("cy"), remaining[0])
+
+    icon_assignments = icons
+
+    winner_idx = set()
+    loser_idx = set()
+    for icon in icon_assignments:
+        if icon.get("player") is None:
+            continue
+        if icon["kind"] == "victory":
+            winner_idx.add(icon["player"])
+        else:
+            loser_idx.add(icon["player"])
+

+    # победителем, и проигравшим (в реальном отчёте так было из-за ложной
+    # иконки легенды «Поражение»). Конфликтных снимаем с ОБЕИХ сторон и
+    # помечаем в raw_data.conflicts — иначе результат выглядит абсурдно.
+    conflicts = winner_idx & loser_idx

+                    "removed from winners/losers",

+        winner_idx -= conflicts
+        loser_idx -= conflicts

+             "name": players[i].get("name"),
+             "both_victory_and_defeat": True}
+            for i in sorted(conflicts))
+
+    win_count = len(winner_idx)
+    lose_count = len(loser_idx)
+
+    # Ничего не распознали — результат неизвестен.
+    if win_count == 0 and lose_count == 0:
+        status = "UNKNOWN"
+        winners, losers = [], []
+        unmatched = list(range(len(players)))
+    # Только поражения — сдача/выход последнего: выжившие = победители.
+    elif win_count == 0 and lose_count > 0:
+        status = "SURRENDER"
+        losers = [_player_summary(players, i) for i in sorted(loser_idx)]
+        winners = [_player_summary(players, i) for i in range(len(players))
+                   if i not in loser_idx]
+        unmatched = []
+    # Есть хотя бы одна победа.
+    else:
+        status = "COMPLETED"
+        winners = [_player_summary(players, i) for i in sorted(winner_idx)]
+        # Проигравшие: только те, у кого найдена иконка поражения; остальных
+        # НЕ угадываем — помечаем как «не распознанных».
+        losers = [_player_summary(players, i) for i in sorted(loser_idx)]
+        matched = winner_idx | loser_idx
+        unmatched = [i for i in range(len(players)) if i not in matched]
+
+    result = {
+        "match_status": status,
+        "winners": winners,
+        "losers": losers,
+        "local_player_team_won": determine_team_victory(winners, losers, players),
+        "unmatched_players": [
+            _player_summary(players, i) for i in unmatched
+        ],
+        "raw_data": {
+            "victory_icons_found": win_count,
+            "defeat_icons_found": lose_count,
+            "unrecognized_lines": sum(
+                1 for i in icon_assignments if i.get("player") is None),
+            "icons": [
+                {
+                    "kind": i.get("kind"),
+                    "cx": i.get("cx"),
+                    "cy": i.get("cy"),
+                    "score": round(float(i.get("score", 0.0)), 3),
+                    "player_index": i.get("player"),
+                    "player": (players[i.get("player")].get("name")
+                               if i.get("player") is not None else None),
+                    "color_side": i.get("color_side"),
+                }
+                for i in icon_assignments
+            ],
+        },
+    }
+    result["raw_data"].update(raw)
+    return result

+#!/usr/bin/env python3
+"""
+Фоновый мониторинг появления экрана статистики (Score Screen).
+
+Работает в отдельном потоке: раз в `poll` секунд делает скриншот (через
+переданный callable), проверяет кадр на ОБА маркера статистики
+(`fortress` + `score_marker`) и, когда экран подтверждён подряд
+`confirm_streak` раз, вызывает callback с кадром. Дальше анализом занимается
+детектор (или сам монитор, если задан analyze-колбэк).
+
+ВАЖНО ПРО ТРИГГЕРЫ:
+  * Декоративный маркер score_screen_marker.png НЕ является признаком
+    экрана статистики — он есть и на других экранах игры (например,
+    «Локальная сеть»), поэтому по нему НЕЛЬЗЯ блокировать ввод.
+  * Тёмное затемнение ТОЖЕ не используется: фейды есть в любом месте игры
+    (старт матча, загрузка, пауза) и не являются признаком статистики.
+  * Единственный допустимый триггер — ПОЛНАЯ рамка экрана статистики:
+    иконка «Крепость» в легенде (fortress_icon.png) + декоративный маркер
+    (score_screen_marker.png) ОДНОВРЕМЕННО, в своих ROI, подряд
+    confirm_streak раз. Это и есть «подтверждающий инструмент»: два
+    независимых шаблона практически исключают ложное срабатывание.
+
+Если скриншот перестал приходить и `game_alive()` сообщает, что игра
+закрылась — монитор останавливается БЕЗ результата (краш игры: результат
+не формируется).

+import logging
+import threading
+import time
+from typing import Callable, Optional
+
+log = logging.getLogger("match_detector.monitor")
+
+
+class ScoreScreenMonitor:
+    """Поток-наблюдатель за появлением экрана статистики."""
+
+    def __init__(self, detector, poll: float = 1.5,
+                 confirm_streak: int = 2,
+                 on_score_screen: Optional[Callable] = None,
+                 on_game_closed: Optional[Callable] = None,
+                 on_timeout: Optional[Callable] = None):
+        """Создать монитор.
+
+        Args:
+            detector: MatchResultDetector (методы _capture_frame(),

+            poll: период опроса, сек.
+            confirm_streak: сколько кадров подряд подтверждают экран

+            on_timeout: callback() если истекло время ожидания экрана.
+        """
+        self._detector = detector
+        self._poll = poll
+        self._confirm_streak = confirm_streak
+        self._on_score_screen = on_score_screen
+        self._on_game_closed = on_game_closed
+        self._on_timeout = on_timeout
+        self._stop = threading.Event()
+        self._thread: Optional[threading.Thread] = None
+        self._timeout: Optional[float] = None
+        self._deadline: Optional[float] = None
+
+    # ------------------------------------------------------------------
+    def start(self, timeout: Optional[float] = None):
+        """Запустить монитор в фоновом потоке.
+
+        Args:
+            timeout: максимальное время ожидания, сек. (None = без лимита).
+        """
+        if self._thread and self._thread.is_alive():
+            log.warning("monitor already running")
+            return
+        self._stop.clear()
+        self._timeout = timeout
+        self._deadline = (time.monotonic() + timeout
+                          if timeout is not None else None)
+        self._thread = threading.Thread(target=self._run, name="score-monitor",
+                                        daemon=True)
+        self._thread.start()
+
+    def stop(self, wait: float = 2.0):
+        """Остановить монитор и дождаться завершения потока.
+
+        Args:
+            wait: максимум секунд ожидания.
+        """
+        self._stop.set()
+        if self._thread and self._thread.is_alive():
+            self._thread.join(timeout=wait)
+        self._thread = None
+
+    def is_alive(self) -> bool:
+        """True, пока поток мониторинга жив."""
+        return bool(self._thread and self._thread.is_alive())
+
+    def wait(self, timeout: Optional[float] = None) -> bool:
+        """Заблокироваться до остановки монитора.
+
+        Args:
+            timeout: сек. (None = до остановки).
+
+        Returns:
+            True, если монитор остановился САМ по результату/закрытию игры;
+            False по таймауту ожидания.
+        """
+        thread = self._thread
+        if not thread:
+            return False
+        thread.join(timeout=timeout)
+        return not thread.is_alive()
+
+    # ------------------------------------------------------------------
+    def _run(self):
+        """Основной цикл: скриншот -> проверка полной рамки -> callback.
+
+        Никаких ранних триггеров (маркер/затемнение): только полная рамка
+        экрана статистики (fortress + score_marker) подряд confirm_streak
+        раз — единственный надёжный «подтверждающий инструмент».
+        """
+        streak = 0
+        misses = 0
+        while not self._stop.is_set():
+            if self._deadline is not None and time.monotonic() > self._deadline:
+                log.warning("timeout waiting for score screen "
+                            "(%.0f s)", self._timeout)
+                self._stop.set()
+                if self._on_timeout:
+                    self._on_timeout()
+                break
+
+            frame = self._detector._capture_frame()
+            if frame is None:
+                misses += 1
+                # Игра ушла/закрылась — мониторинг бессмысленен.
+                if misses >= 3 and self._detector._game_alive \
+                        and not self._detector._game_alive():
+                    log.info("game process closed — monitoring stopped "
+                             "without result")
+                    if self._on_game_closed:
+                        self._on_game_closed()
+                    self._stop.set()
+                    break
+                time.sleep(self._poll)
+                continue
+
+            misses = 0
+
+            # Единственный путь: полная рамка экрана статистики
+            # (fortress + score_marker). Два независимых маркера исключают
+            # ложные срабатывания на боевом HUD (там тоже есть иконки
+            # крепостей) и на других экранах игры (маркер «Счёт» есть и
+            # на «Локальной сети» — поэтому по нему ОДНОМУ нельзя).
+            if self._detector.is_score_screen(frame):
+                streak += 1
+                log.debug("score screen candidates: %d/%d",
+                          streak, self._confirm_streak)
+                if streak >= self._confirm_streak:
+                    log.info("score screen detected")
+                    if self._on_score_screen:
+                        self._call(self._on_score_screen, frame)
+                    self._stop.set()
+                    break
+            else:
+                streak = 0
+
+            time.sleep(self._poll)
+
+    @staticmethod
+    def _call(cb: Callable, *args):
+        """Вызвать callback, не давая ему уронить поток монитора."""
+        try:
+            cb(*args)
+        except Exception:  # noqa: BLE001 - монитор не должен умирать
+            log.exception("monitor callback failed")

+            color_name = _nearest_lobby(rgb)

+def _paste(img, tpl, x, y):
+    """Вставить шаблон (RGB с тёмным фоном) на кадр."""
+    th, tw = tpl.shape[:2]

+def _draw_hline(img, x0, x1, y, color, thick=LINE_THICKNESS):
+    """Нарисовать горизонтальную линию."""
+    img[y - thick // 2:y + thick // 2 + 1, x0:x1] = color

+def _draw_sloped(img, x0, x1, y_end, color, thick=LINE_THICKNESS,
+                 slope=0.25):
+    """Нарисовать линию, поднимающуюся к правому краю (как на таймлайне).
+
+    y(x) = y_end + slope * (x1 - x) — у иконки (x1) линия на y_end,
+    левее она ниже (в кадре y больше). Real-кадры «Счёта»: линии идут к
+    иконкам под наклоном (зелёная ≈ 0.4 px/px, жёлтая ≈ 0.7 px/px).
+    """
+    for x in range(int(x0), int(x1)):
+        yy = int(round(y_end + slope * (x1 - x)))
+        img[yy - thick // 2:yy + thick // 2 + 1, x] = color

+def _plain_frame():
+    """Кадр БЕЗ шаблонов статистики.
+
+    Тёмный фон + небольшой яркий блок (как у реального «Счёта»), чтобы кадр
+    проходил фильтр «чёрного кадра» в _capture_frame. Здесь нет ни маркера,
+    ни легенды, ни иконок — такой кадр НЕ может вызвать блокировку ввода.
+    """
+    frame = np.zeros((1080, 1920, 3), dtype=np.uint8)
+    frame[:, :] = (12, 14, 20)

+def _marker_only_frame(bright_bg=False):
+    """Кадр с декоративным маркером «Счёт», но БЕЗ легенды и иконок.
+
+    Имитирует самую раннюю стадию появления экрана статистики: маркер уже
+    отрисован (он появляется первым), а легенда «Крепость» и иконки исхода
+    на графике — ещё нет. Именно в этот момент должна срабатывать ранняя
+    блокировка ввода.
+    """
+    from match_result_detector.config import TEMPLATE_FILES, TEMPLATES_DIR
+    from match_result_detector import icon_finder as _finder
+    frame = _plain_frame()
+    if bright_bg:
+        frame[:, :] = (150, 150, 150)  # яркий фон — тёмный триггер не нужен
+    tpl = _finder.load_png(str(TEMPLATES_DIR / TEMPLATE_FILES["score_marker"]))
+    h, w = tpl.shape[:2]
+    # Реальное положение маркера @1080p: верхний левый угол ≈ (1325, 0).
+    frame[0:h, 1325:1325 + w] = tpl
+    return frame

+def _staircase_frame():
+    """Кадр со СТУПЕНЧАТЫМИ линиями, как на реальных вкладках статистики.
+
+    Линии таймлайна на «Войска/Постройки/Ресурсы/Счёт» — step-функции
+    (горизонтальные плато + вертикальные скачки), а не наклонные прямые.
+    Цвета ниток сильно темнее палитры (синяя ~[37,45,82] при базе
+    [78,90,132]). Здесь: синяя ступенька приходит к монете слева, белая
+    вертикаль подходит к пламени сверху (положения как на stats_4).
+    """
+    from match_result_detector.config import TEMPLATE_FILES, TEMPLATES_DIR
+    from match_result_detector import icon_finder as _finder
+    f = _plain_frame()
+    # --- синяя линия к монете (victory): дальнее плато y=430, вертикальный
+    # скачок вверх, коннектор на уровне иконки y=400 ---
+    blue = (37, 45, 82)
+    for x in range(1050, 1207):
+        f[428:431, x] = blue          # дальнее плато (ниже иконки)
+    for y in range(400, 460):
+        f[y, 1208:1211] = blue        # длинная вертикаль (вне лучей монеты)
+    for x in range(1208, 1228):
+        f[399:402, x] = blue          # коннектор на уровне иконки
+    # белая линия к пламени (defeat): вертикаль сверху y=140..270,
+    # плато остаётся выше (140)
+    white = (133, 146, 154)
+    for y in range(140, 270):
+        f[y, 1208:1211] = white
+    for x in range(1120, 1210):
+        f[138:141, x] = white
+    # --- иконки исхода в реальных позициях (как на скриншотах) ---
+    # монета на (1253, 400): центр; шаблон 57x49 -> верхний левый угол ~(1224, 375)
+    for name, cx, cy in (("victory", 1253, 400), ("defeat", 1210, 281)):
+        tpl = _finder.load_png(str(TEMPLATES_DIR / TEMPLATE_FILES[name]))
+        th, tw = tpl.shape[:2]
+        x, y = cx - tw // 2, cy - th // 2
+        f[y:y + th, x:x + tw] = np.maximum(f[y:y + th, x:x + tw], tpl)
+    return f
+

+    анализу иконки победы/поражения на графике.
+    """
+    from match_result_detector.config import TEMPLATE_FILES, TEMPLATES_DIR
+    from match_result_detector import icon_finder as _finder
+    frame = _marker_only_frame()
+    # Легенда «Крепость» внизу слева (fortress_roi: x 220..420, y 840..900).
+    tpl = _finder.load_png(str(TEMPLATES_DIR / TEMPLATE_FILES["fortress"]))
+    h, w = tpl.shape[:2]
+    frame[844:844 + h, 221:221 + w] = tpl
+    # Иконки исхода на графике (chart_roi: x 190..1310, y 240..815).
+    for name, x, y in (("victory", 1150, 350), ("defeat", 650, 620)):
+        tpl = _finder.load_png(str(TEMPLATES_DIR / TEMPLATE_FILES[name]))
+        h, w = tpl.shape[:2]
+        frame[y:y + h, x:x + w] = tpl
+    return frame

+class TestWaitScoreMarker(unittest.TestCase):
+    def _set_capture(self, frames):
+        state = {"i": 0}
+        def capture(print_fallback=False):
+            i = state["i"]
+            state["i"] += 1
+            return frames[min(i, len(frames) - 1)]
+        screen_ready.nav.capture_window = capture
+        self.addCleanup(lambda: setattr(screen_ready.nav,
+                                        "capture_window", lambda: None))
+        return state
+
+    def test_wait_found_after_frames(self):
+        self._set_capture([_plain(), _with_marker(), _with_marker()])
+        ok = screen_ready.wait_score_marker(poll=0.01, timeout=5.0,
+                                            confirm=2, settle=0.0)
+        self.assertTrue(ok)
+
+    def test_wait_timeout_when_marker_absent(self):
+        self._set_capture([_plain()])
+        t0 = time.monotonic()
+        ok = screen_ready.wait_score_marker(poll=0.01, timeout=0.2,
+                                            confirm=2, settle=0.0)
+        self.assertFalse(ok)
+        self.assertLess(time.monotonic() - t0, 3.0)
+
+    def test_wait_confirm_resets_on_gap(self):
+        # Маркер мелькнул и пропал: streak сбрасывается, ждём заново.
+        self._set_capture([_with_marker(), _plain(), _with_marker(),
+                           _with_marker()])
+        ok = screen_ready.wait_score_marker(poll=0.01, timeout=5.0,
+                                            confirm=2, settle=0.0)
+        self.assertTrue(ok)
+
+    def test_wait_settle_delays_return(self):
+        self._set_capture([_with_marker(), _with_marker()])
+        t0 = time.monotonic()
+        ok = screen_ready.wait_score_marker(poll=0.01, timeout=5.0,
+                                            confirm=2, settle=0.2)
+        self.assertTrue(ok)
+        self.assertGreaterEqual(time.monotonic() - t0, 0.2 - 0.05)
