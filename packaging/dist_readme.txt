BFME2: RotWK — КАЛИБРАТОР (координаты меню + маркер готовности)
================================================================

ЧТО ЭТО
-------
Утилита запускает игру в оконном режиме и даёт снять:
  * МАРКЕР готовности (F8) — кусочек экрана с треугольником-индикатором
    выпадающего списка. По нему мост понимает, что меню уже отрисовано.
  * КООРДИНАТЫ кнопок (F9) — в долях окна (0..1), поэтому работают на
    любом разрешении.

ТРЕБОВАНИЯ
----------
  * Windows 10/11 x64;
  * установленная BFME2: Rise of the Witch-king (RotWK);
  * Python НЕ нужен (всё внутри Calibrate.exe);
  * игра должна быть ЗАКРЫТА перед запуском.

ЗАПУСК
------
1. Закрой игру.
2. Двойной клик по Calibrate.exe -> в UAC нажми «Да».
   (Права администратора обязательны: без них Windows молча выбрасывает
   клики, посланные в окно игры.)
3. Дождись главного меню игры.
4. Alt-Tab в игру, наведи курсор:
      F8  — на треугольник над кнопкой со списком -> сохранится маркер;
      F9  — на нужную кнопку -> координата появится в консоли;
      F10 — выход.

КУДА ПИШЕТСЯ РЕЗУЛЬТАТ
----------------------
Всё — в папку config\ РЯДОМ С ЭКЗЕШНИКОМ:
  config\menu_marker.npy        маркер (картинка)
  config\menu_marker.json       позиция маркера в долях окна
  config\calibrate_coords.txt   все снятые координаты + готовые строки
                                вида [0.3019, 0.9244], для menu_positions.json
  config\config.json            путь к игре (можно поправить руками)
  calibrate_log.txt             лог (пришли его, если «не работает»)

ЕСЛИ ИГРА НЕ НАЙДЕНА
--------------------
Утилита ищет игру в реестре и в типовых папках. Если не нашла — открой
config\config.json и впиши свой путь (двойные слеши обязательны):

    {
      "exe_path": "D:\\Games\\RotWK\\lotrbfme2ep1.exe"
    }

КЛЮЧИ КОМАНДНОЙ СТРОКИ
----------------------
  --attach                 не запускать игру, подключиться к уже открытой
  --exe "путь"             путь к игре (вместо config.json)
  --no-resolution          не менять Resolution в Options.ini
  --resolution "1024 768"  своё разрешение на время калибровки
  --marker-size 0.05       сторона маркера в долях окна (по умолчанию 0.03)
  --wait 180               дольше ждать окно игры (сек)
  --no-pause               не ждать Enter перед закрытием окна

Пример: cmd -> Calibrate.exe --attach

ЕСЛИ АНТИВИРУС РУГАЕТСЯ
-----------------------
Однофайловые exe, собранные PyInstaller, иногда ложно помечаются. Варианты:
добавить папку в исключения, либо собрать у себя
(build_calibrate_exe.bat в исходниках), либо запускать calibrate.bat из
исходников — он делает то же самое через Python.

ГОРЯЧИЕ КЛАВИШИ НЕ СРАБАТЫВАЮТ
------------------------------
F8/F9/F10 могут быть заняты другим софтом (драйверы клавиатуры, оверлеи).
Закрой их и запусти калибратор заново.
