Калибратор BFME2: RotWK — как пользоваться
==========================================

1. Распакуй этот архив в ЛЮБУЮ обычную папку (не в Program Files и не
   прямо из окна архиватора — утилита пишет рядом с собой настройки).

2. Закрой игру, если она запущена.

3. Двойной клик по  calibrate.bat
   -> в окне UAC нажми «Да» (без прав администратора Windows молча
      выбрасывает клики, посланные в окно игры).

4. При ПЕРВОМ запуске bat сам найдёт Python, а если его нет — скачает
   портативный (~11 МБ) в папку .runtime\ и поставит numpy. Нужен
   интернет, один раз. Дальше всё работает офлайн.
   Ничего устанавливать вручную не требуется.

5. Дождись главного меню игры, нажми Alt-Tab в игру и наводи курсор:

      F8   сохранить МАРКЕР готовности (наведи на треугольник-индикатор
           над кнопкой с выпадающим списком)
      F9   снять КООРДИНАТУ кнопки (появится в консоли и в файле)
      F10  выход

Куда сохраняется результат (в папке config\ рядом с calibrate.bat):

  menu_marker.npy        картинка маркера
  menu_marker.json       позиция маркера в долях окна
  calibrate_coords.txt   все снятые координаты + готовые строки вида
                         [0.3019, 0.9244],  для menu_positions.json
  config.json            путь к игре
  ..\calibrate_log.txt   лог запуска

Если игра не найдена
--------------------
Открой config\config.json и впиши свой путь (двойные слеши обязательны):

    {
      "exe_path": "D:\\Games\\RotWK\\lotrbfme2ep1.exe"
    }

Полезные ключи (запускать из cmd в этой папке):

    calibrate.bat --attach                 игра уже открыта, не запускать
    calibrate.bat --exe "путь\к\игре.exe"  путь к игре вручную
    calibrate.bat --no-resolution          не менять Resolution в Options.ini

Не получается? Пришли файл calibrate_log.txt — в нём видно, на каком шаге
всё остановилось.
