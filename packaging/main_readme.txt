BFME2: RotWK — Автоматический запуск и настройка боя

1. Положите файл с координатами рядом с Main.exe:
   - coordinates.txt  — для обычной карты
   - _coordinates.txt — для карты-крепости (название начинается с подчеркивания)

   Формат строк координат:
   2026-08-27 17:13:06  frac=(0.4906, 0.3514)  px=(1192,488)  ->  [0.4906, 0.3514],
   (первые 4 строки — оборона, следующие 4 строки — атака).

2. Запустите Main.exe двойным кликом (подтвердите UAC-запрос «Да»).
3. Ответьте на вопросы в консоли: сложность, число игроков, фракция, роль (защита/атака), расстановка (по приоритету/случайно).
   Для крепости программа также спросит, кто владелец крепости.
4. Main.exe автоматически настроит комнату и запустит бой!
